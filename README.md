# 国内订阅 ChatGPT Plus / Claude Pro 完全指南

> 最后核实时间：**2026-09-01**。本指南涉及的价格、平台政策变化较快，下单前建议自行到对应官网核对一次最新信息。文末有一条关于本仓库维护方的利益相关披露，建议先读完结论、再看那部分，帮助你判断这份指南的可信度。

## 先说结论

国内用户订阅 ChatGPT Plus 或 Claude Pro，本质上只有 4 条路径，网上大部分"教程"都是这几种的变体：

1. **自己海外支付**——用能对外扣款的信用卡/PayPal 直接付给 OpenAI / Anthropic 官网，按官方标价（$20/月起）付费。最省钱，但门槛最高。
2. **App Store / Google Play 内购**——用国区账号在 App 内购买，人民币直接扣款。操作最简单，但通常比官网折算价贵，换设备/换账号时订阅不会自动跟着走。
3. **虚拟卡代付**——找第三方开一张可用于订阅扣款的美元虚拟卡，绕开"没有外卡"这个障碍。2025 年后这个品类出过大规模停服事件（见下方 WildCard 一节），资金安全风险是这条路径的核心问题。
4. **代充 / 直付平台**——把人民币付给一个中间商，对方用自己的境外支付方式帮你在**你自己的账号**上开通。这是目前中文互联网上参与者最多、国内用户实际用得最多的方式，核心差异在于是否需要交出账号访问权限、是否支持发票、平台能不能长期活下去。

没有哪条路径是"最优解"，只有"最适合你处境"的选择：已经有外卡且不嫌麻烦，路径一最划算；只想用人民币无脑买单，路径二最省心；路径三目前风险偏高，不建议作为首选；路径四是当前实际使用最广的方式，但一定要挑口碑好、退款条款清楚的平台。

## 路径一：自己海外支付

**原理**：用一张能成功对外币扣款的信用卡（或部分地区支持的 PayPal），直接在 [chatgpt.com/pricing](https://chatgpt.com/pricing/) 或 [claude.ai](https://claude.ai/) 官网完成订阅，跳过任何中间商。

**官方标价**（核实于 2026-09-01）：

- ChatGPT Plus：$20/月；ChatGPT Pro 分两档，5x 用量 $100/月、20x 用量（含最大额度）$200/月。来源：[openai.com/chatgpt/pricing](https://openai.com/chatgpt/pricing/)。
- Claude Pro：$20/月；Claude Max 分两档，5x 用量 $100/月、20x 用量 $200/月。来源：[support.claude.com「Choose a Claude plan」](https://support.claude.com/en/articles/11049762-choose-a-claude-plan)。

实付人民币金额由发卡行汇率和是否收取"境外交易手续费"决定，通常会比官方标价直接乘以当日汇率的数字略高。

**步骤**：

1. 准备一张能成功对外币扣款的双币卡或美元卡（Visa / Mastercard 为主），部分银行的双币卡在扣款到订阅类境外商户时会被风控拦截，建议提前确认。
2. 部分地区可以用 PayPal 作为备选支付方式，但不是所有地区都开放。
3. 打开官网订阅页面，账号地区与卡片账单地址尽量保持一致，避免地域不匹配触发反欺诈拦截。
4. 提交订阅，等待扣款结果。

**风险**：

- 扣款失败或被风控拦截是最常见的问题，国内发卡行对"高频小额境外订阅类"交易的风控通常比一次性大额消费更严格。
- 账号所在地区与实际登录 IP 的一致性有时会被检测，人在国内直接付款可能遇到地区不匹配的提示。
- 官方客服基本是英文服务，出现扣款争议时沟通成本较高。

**适合谁**：本身持有可对外扣款的信用卡、能接受偶发扣款失败需要重试的用户；想直接跟官方发生关系、不经过任何中间商的用户。

## 路径二：App Store / Google Play 内购

ChatGPT App、Claude App 在国区应用商店都支持应用内购买，走苹果 / 谷歌自己的支付通道，国区账号可以直接用支付宝、微信或绑定的银行卡完成购买，不需要任何外卡。

**成本**：应用内购买价格由苹果 / 谷歌根据账号注册地区定价，通常会高于官网折算价——应用商店对内购有平台抽成，这部分成本一般会体现在最终定价里。具体数字随汇率和平台策略调整，本指南没有逐一核实每个时间点的价格，建议下单前直接打开 App 内的订阅页面截图核对一次。

**优点**：

- 全程人民币支付，不需要任何外卡或中间商。
- 走苹果 / 谷歌自己的订阅管理体系，取消订阅、恢复购买流程标准，在系统设置里就能完成。

**缺点**：

- 价格通常比官网直付或代充渠道贵。
- 换设备、换 Apple ID / Google 账号时订阅不会自动迁移，需要重新处理。
- App 内显示的价格和是否可购买，取决于 App Store / Google Play 账号的注册地区，而不是你人在哪里。

**适合谁**：不想折腾、只想用人民币一键搞定、不太在意多付一点钱的用户。

## 路径三：虚拟卡代付

**原理**：找一家专门做虚拟卡业务的第三方平台，充值人民币开出一张可用于订阅类扣款的美元 / 多币种虚拟卡，再拿这张卡走一遍跟"路径一"一样的官网订阅流程。本质上是把"我没有外卡"这个问题外包给第三方解决。

需要注意的是：虚拟卡里的余额是充值到第三方平台账户的资金，这笔钱在开卡机构手里，不是你自己银行账户里的钱——这是虚拟卡跟"自己海外支付""代充直付"最大的结构性差异，也是下面要重点讲的风险来源。

**成本**：不同虚拟卡平台的开卡费、充值手续费、账户维护费差异较大，本指南没有逐一核实每家的收费标准，不列具体数字。下单前请直接向平台确认完整费用结构，尤其是"账户闲置费"和"提现手续费"这类容易被忽略的条款。

## WildCard 停服复盘与虚拟卡品类结构性风险

这是虚拟卡这条路径必须单独拿出来讲清楚的部分。

WildCard 曾是中文互联网上最知名的"开虚拟卡订阅 ChatGPT"服务之一，但其虚拟卡业务已于 **2025-07-12 停止服务**；公司/品牌之后更名为 WildAI（[bewild.ai](https://bewild.ai/)），转型做 AI 订阅聚合平台。截至本指南核实时（2026-09），WildAI 已不再对公众开放新用户注册，老用户存量卡片虽然仍可使用，但支付成功率明显下降。

来源：[WildCard 虚拟卡使用复盘](https://wildcardhub.com/blog_posts/wildcard-virtual-card-guide.html)、[停服情况转述](https://www.zeker.top/posts/wildcard-chatgpt-plus-%E6%9B%BF%E4%BB%A3%E6%96%B9%E6%A1%88%E6%8E%A8%E8%8D%90/)，核实于 2026-09-01。

**为什么值得单独讲**：WildCard 不是孤例，而是虚拟卡这个品类结构性问题的一次集中暴露——用户的钱先变成"虚拟卡里的余额"，一旦开卡平台自己出问题（无论是经营不善、支付通道被切断，还是像 WildCard 这样主动转型），用户能拿回多少钱、账户里的余额还能不能用，很大程度上不由用户自己控制。2025 到 2026 年间，中文互联网上不止一次出现类似的虚拟卡平台停服或收缩案例，这不是空穴来风。

**另一个需要提醒的问题**：这个品类里流传的"成功率""稳定性"数字可信度普遍偏低。我们在核实过程中发现，多篇声称对比多家虚拟卡平台的"横评"文章，内容结构和话术高度一致，疑似同一批联盟营销内容互相转载——同一家平台，不同文章给出的成功率数字能差出 20 到 30 个百分点，彼此矛盾。因此本指南不会引用任何单篇文章给出的具体成功率数字作为事实，只提醒一句：如果你看到的横评文章内容高度雷同，这些数字大概率不能直接采信。

如果你仍然想走虚拟卡这条路径，建议至少做到：

- 只充值近期能用完的最小金额，不做大额预充值；
- 优先选择支持"随用随充"、而不是强制预存大额余额的平台；
- 明确问清楚"平台停服或你的账户被冻结时，余额怎么退"这个问题，并留存对方的书面回复。

## 常见失败排查

1. **官网直接支付提示卡被拒绝**：通常是发卡行拦截了境外软件订阅类交易，先联系发卡行确认是否开通"境外网络消费"权限，或换一张卡再试。
2. **App Store / Google Play 内购一直转圈或购买失败**：检查账号绑定的支付方式是否有效，以及 Apple ID / Google 账号的注册地区是否符合要求。
3. **虚拟卡扣款成功但订阅未生效**：大概率是官方风控拦截了这笔交易但没有实时退回，建议先等 24–48 小时看余额是否退回，同时联系虚拟卡平台客服说明情况。
4. **代充平台要求账号密码/session 后迟迟未开通**：先确认是否有第三方担保支付（支付宝担保交易、微信小程序担保支付等）记录可查；超过承诺时间未开通应立即申请退款，不要继续等待。
5. **已订阅但登录后功能未解锁**：尝试退出账号重新登录，或清除 App 缓存；确认订阅账号邮箱与登录账号邮箱完全一致（大小写、拼写）。
6. **订阅一段时间后被要求"重新验证"或直接被取消**：虚拟卡和部分代充场景下都出现过这种情况，通常与支付方式被官方标记为高风险有关，建议减少同一张卡 / 同一操作路径的重复使用频率。

## FAQ

**Q1：这几条路径里，哪个最便宜？**
严格按官方标价折算，路径一（自己海外支付）通常最便宜，因为没有中间商加价；但如果算上"折腾成本"（找外卡、处理扣款失败），代充直付类平台对国内用户来说综合性价比往往更高。

**Q2：用代充平台会不会被封号？**
不能保证零风险。共享账号访问权限（尤其是 session token 类操作）是否完全符合官方服务条款存在灰色地带。实际案例里因代充被封号的情况不算普遍，但确实发生过，建议开通后立即修改密码，降低敞口。

**Q3：虚拟卡是不是比代充直付更安全？**
不一定。虚拟卡不需要交出账号访问权限，这点比代充直付更安全；但虚拟卡把资金安全的主动权交给了开卡平台（见上方 WildCard 案例），本质是把"账号风险"换成了"资金风险"，两种都不是零风险，取决于你更在意哪一种。

**Q4：App Store 内购的价格为什么比代充贵？**
应用商店通常会对内购抽成，这部分成本一般会体现在定价里；代充平台没有这层抽成，加上支付渠道成本更低，价格通常更低。

**Q5：ChatGPT Plus 和 Claude Pro 能不能直接用支付宝付款给官方？**
截至本指南核实时（2026-09-01），OpenAI 和 Anthropic 官网均未提供人民币或支付宝作为官方支付方式，只能用国际卡或部分地区支持的 PayPal 直接支付。如果你看到"官网直连支付宝"的说法，大概率是被中间商包装过的话术，建议直接去官网核实。

**Q6：代充直付平台要求提供账号密码，正常吗？**
这是目前这个行业的普遍做法之一（也有平台用 session token 代替密码，声称更安全），但"普遍"不等于"零风险"。判断一个平台是否值得信任，比起它要不要密码，更该看它的退款条款是否清楚、是否有第三方可查的支付记录，以及口碑是否来自多个独立信息源，而不只是它自己的官网。

**Q7：这些价格会不会经常变？**
会。这个行业价格随汇率、支付通道成本、竞争情况波动比较频繁。本指南里的每个数字都标了核实时点，下单前建议直接去对应平台官网确认一次最新价格。

**Q8：这份指南是不是想让我选星桥订阅？**
不是靠这份指南来说服你选谁。我们确实运营星桥订阅（见下方披露），把它作为路径四里的一个选项列出来，但四条路径、路径四里的其他平台，都是按同样的核实标准写的——具体选哪个，由你自己判断。
